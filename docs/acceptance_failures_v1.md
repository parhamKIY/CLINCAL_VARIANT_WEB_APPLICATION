# Stage 79 Acceptance Failure Registry

This registry freezes the historical report-first acceptance baseline. The
confidential professor report is the **authoritative visual and structural reference**
and is retained only as a **local confidential design reference**.

No current application screenshot is committed as a substitute for that reference.

These IDs preserve the Stage 79 acceptance contract; they are historical baseline
items, not a claim that their later report-first implementation outcomes remain
unresolved.

| ID | Frozen acceptance failure | Required outcome |
|---|---|---|
| AF-01 | Output is provider-dashboard-first instead of report-first. | Open on a per-variant clinical report. |
| AF-02 | Report anatomy does not follow the approved four-page family. | Preserve the required section order and hierarchy. |
| AF-03 | Multiple accepted alleles can be visually conflated. | Produce one independently reviewable artifact per allele. |
| AF-04 | Missing evidence is ambiguous. | State valid missingness explicitly without implying provider failure. |
| AF-05 | Literature and database provenance are mixed. | Keep numbered literature separate from unnumbered data sources. |
| AF-06 | Reviewer edits and inclusion decisions are not sufficiently traceable. | Preserve immutable generated content and append-only review history. |
| AF-07 | Visual fidelity lacks a reproducible gate. | Validate structure automatically and retain an explicit manual visual gate. |

The synthetic Stage 79 fixture is non-PHI and exists only to preserve acceptance
structure, identity, missingness, and source-category expectations.
